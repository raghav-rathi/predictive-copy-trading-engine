# 1-2-3 Reversal

Joe Ross 1-2-3 reversal on 5-bar fractal pivots. Bullish: point 1 is the fractal low ending a decline, point 2 the high of the first rally off point 1, point 3 a pullback low holding above point 1. The 1→2 leg must be ≥ 1.0x ATR(14); if point 3 falls to/below point 1 the pattern is void. The pattern completes on a close above point 2. Bearish is the mirror image.

## Rules

- Long: bullish 1-2-3 active (point 3 confirmed, holding above point 1) and the close breaks above point 2 — enter on that bar, once per pattern.
- Short: bearish 1-2-3 active and the close breaks below point 2.
- Exit long: close below point 3 (invalidation) or an opposite (bearish) 1-2-3 completion (close below the bearish point 2). Exit short is the mirror.
- While a pattern is active, a newer confirmed pullback extreme below the current point 3 (but still beyond point 1) updates point 3 to the deeper pullback low; a close through point 1 voids the pattern.
- Pivots are 5-bar local extrema with a minimum 0.9x ATR(14) swing, usable only 2 bars after the extreme bar — no lookahead.
