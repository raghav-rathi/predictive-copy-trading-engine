# Volume Oscillator

Volume Oscillator (5/10): long on the oscillator crossing above zero while price is above its 20-bar average; short on crossing below zero while price is below it; exit on the opposite cross.

Source: Volume Oscillator (Buff Dormeier / volume-analysis canon) — https://www.investopedia.com/terms/v/volume-oscillator.asp

Paper only: historical/backtest signals, no live execution.
