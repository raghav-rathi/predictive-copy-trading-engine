# Tweezer Top / Bottom

Two bars sharing a high (top) or low (bottom) within 0.15%, second bar closing back inside.

Source: Steve Nison, Japanese Candlestick Charting Techniques (Tweezers Tops and Bottoms) — https://epage.pub/doc/6-japanese-candlestick-charting-techniques-by-steve-nison-yvm9x4p2dy

Paper only: historical/backtest signals, no live execution.
