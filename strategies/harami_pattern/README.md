# Harami Pattern

Small body fully contained in a preceding large body, direction by the small body's color.

Source: Steve Nison, Japanese Candlestick Charting Techniques (Harami Pattern) — https://epage.pub/doc/6-japanese-candlestick-charting-techniques-by-steve-nison-yvm9x4p2dy

Paper only: historical/backtest signals, no live execution.
