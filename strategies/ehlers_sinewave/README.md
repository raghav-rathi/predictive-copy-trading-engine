# Ehlers SineWave

Even Better SineWave (Ehlers): sine/lead-sine cross in cycle mode; long on sine crossing above lead sine, short on crossing below.

Source: John Ehlers SineWave / Even Better Sinewave (MESA) — https://www.quantconnect.com/forum/discussion/940/john-ehlers-sine-wave-indicator/p1

Paper only: historical/backtest signals, no live execution.
