# Harmonic Gartley XABCD

Zigzag (5-bar-confirmed) swing pivots scanned for the classic Gartley:
AB=0.618·XA, BC∈[0.382,0.886]·AB, CD∈[1.272,1.618]·BC, AD=0.786·XA
(±6% on the point ratios). Long on bullish PRZ completion, short on
bearish; exit on a fresh opposite pattern. 2xATR stop (proxy for the
classical stop-beyond-X — see BACKTEST.md), 4xATR target, 100-bar max
hold.

Source: https://www.ebc.com/forex/gartley-pattern-explained-a-guide-to-this-powerful-setup
