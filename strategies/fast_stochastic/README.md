# Lane Fast Stochastic

Lane Fast Stochastic %K(14)/%D(3): long on %K crossing above %D while %D is oversold (<20), short on crossing below %D while %D is overbought (>80).

Source: George Lane Fast Stochastic (Technical Analysis of Stocks & Commodities) — https://www.investopedia.com/terms/s/stochasticoscillator.asp

Paper only: historical/backtest signals, no live execution.
