# Marubozu Breakout

Nison marubozu: a candle whose body is >= 90% of its range is a conviction candle — long on a bullish marubozu close, short on a bearish one; exit on the opposite marubozu.

Source: Steve Nison marubozu (Japanese Candlestick Charting Techniques) — https://www.investopedia.com/terms/m/marubozu.asp

Paper only: historical/backtest signals, no live execution.
