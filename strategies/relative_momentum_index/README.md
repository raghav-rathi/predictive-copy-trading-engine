# Relative Momentum Index

Roger Altman RMI(20,5): Wilder-smoothed gains/losses measured close-vs-close-5-bars-ago instead of consecutive closes; long on a cross above 50, short on a cross below 50.

Source: Roger Altman Relative Momentum Index (Technical Analysis of Stocks & Commodities, Feb 1993) — https://patternswizard.com/relative-momentum-index/

Paper only: historical/backtest signals, no live execution.
