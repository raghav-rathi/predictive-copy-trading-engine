# Morning Star / Evening Star

Large candle + gapped small star + close past the first candle's midpoint.

Source: Steve Nison, Japanese Candlestick Charting Techniques (Morning/Evening Star) — https://epage.pub/doc/6-japanese-candlestick-charting-techniques-by-steve-nison-yvm9x4p2dy

Paper only: historical/backtest signals, no live execution.
