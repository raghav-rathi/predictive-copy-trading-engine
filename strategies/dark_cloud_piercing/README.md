# Dark Cloud Cover / Piercing Line

Second candle opens beyond the first's extreme and closes past its midpoint.

Source: Steve Nison, Japanese Candlestick Charting Techniques (Dark-Cloud Cover / Piercing Pattern) — https://epage.pub/doc/6-japanese-candlestick-charting-techniques-by-steve-nison-yvm9x4p2dy
