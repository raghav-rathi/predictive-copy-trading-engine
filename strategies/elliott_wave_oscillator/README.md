# Elliott Wave Oscillator

Bill Williams Elliott Wave Oscillator: SMA(5) minus SMA(35) of closes. Long on a zero-line cross up confirmed by a rising SMA(50); short on a zero-line cross down confirmed by a falling SMA(50); exit on the opposite zero cross.

## Rules

- Long: EWO crosses above 0 while SMA(50) is rising.
- Short: EWO crosses below 0 while SMA(50) is falling.
- Exit: opposite zero-line cross (plus ATR stop / chandelier trail).
